A low >= high error comes after all individual field checks. Preserve no unrelated keys in responses. Use exactly the listed success keys and failure shape. Implementation will be compiled under TypeScript strict mode and run against unseen oracle-derived cases. Create only `port.ts` in the working directory. Do not use external tools beyond reading these supplied files and writing the implementation.
